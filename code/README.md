# โค้ดตัวอย่าง — อ่านค่าจากเครื่องวัดความดันผ่าน RS-232

เอาไปใช้ ดัดแปลง ต่อยอดได้เลย — เผยแพร่ภายใต้สัญญาอนุญาต [MIT](../LICENSE)

**ลองเล่นได้แม้ยังไม่มีเครื่องจริง** — มีตัวจำลองเครื่องวัดความดันให้ในชุดนี้

---

## เริ่มใน 1 นาที

ต้องมี Python 3.8 ขึ้นไป

```bash
pip install pyserial

# ดูว่าเฟรมที่เครื่องส่งออกมาหน้าตาเป็นอย่างไร — ไม่ต้องมีเครื่อง ไม่ต้องมีพอร์ต
python device_simulator.py --dry-run --device terumo_br500 --sys 119 --dia 76 --pulse 83
```

จะได้

```
device : Terumo BR-500  [9600-8-N-1]
HEX    : 02 52 31 2C 30 30 30 ... 03 EC
TEXT   : <STX>R1,000000000,260913,223017,119,090,076,083,0000,0000,00000,000<ETX><EC>
```

นั่นคือสิ่งที่เครื่องวัดความดันพูดออกมาจริง ๆ

```bash
# ทดสอบว่าทุกอย่างทำงานถูก
python test_profiles.py
```

ควรได้ `passed 49  failed 0`

---

## ลองทั้งวงจรโดยไม่มีเครื่อง

ต้องมีคู่พอร์ตจำลอง — ลง [com0com](https://sourceforge.net/projects/com0com/) (ฟรี)
หรือ HHD Virtual Serial Port Tools แล้วสร้างคู่ เช่น COM3 ⇄ COM4

เปิดสองหน้าต่าง

```bash
# หน้าต่างที่ 1 — ทำตัวเป็นเครื่องวัดความดัน
python device_simulator.py --device terumo_br500 --port COM4

# หน้าต่างที่ 2 — อ่านค่า
python device_reader.py --device terumo_br500 --port COM3
```

กด Send ในตัวจำลอง แล้วดูค่าขึ้นที่ตัวอ่าน

## ไฟล์ในชุดนี้

| ไฟล์ | ทำอะไร |
|---|---|
| `device_profile.py` | แกนกลาง — สร้างเฟรม แยกเฟรม คิด checksum ตาม profile |
| `device_simulator.py` | จำลองเครื่องวัดความดัน ส่งข้อมูลออกทาง COM port |

| `test_profiles.py` | ชุดทดสอบ |
| `profiles/*.json` | คำอธิบายเครื่องแต่ละรุ่น |

## แนวคิดหลัก — Device Profile

แทนที่จะเขียนโปรแกรมใหม่ทุกครั้งที่เจอเครื่องรุ่นใหม่
**อธิบายเครื่องเป็นข้อมูล แล้วใช้โค้ดชุดเดียวอ่านทุกเครื่อง**

```json
{
  "name": "Terumo BR-500",
  "port":    { "baud": 9600, "dataBits": 8, "parity": "none", "stopBits": 1 },
  "framing": { "stx": "0x02", "etx": "0x03", "checksum": "sum8" },
  "body":    { "delimiter": ",", "recordId": "R1", "minFields": 8 },
  "fields":  { "sys": 4, "map": 5, "dia": 6, "pulse": 7 }
}
```

ไฟล์เดียวกันนี้ใช้ได้ทั้งสองทาง — ตัวอ่านใช้แยกเฟรม ตัวจำลองใช้สร้างเฟรม

**เพิ่มเครื่องใหม่ = เพิ่มไฟล์ JSON ไม่ต้องแตะโค้ด**

## เครื่องที่มี profile ให้แล้ว

| เครื่อง | สถานะ |
|---|---|
| **Terumo BR-500** | ✅ ยืนยันกับเครื่องจริงแล้ว |
| Omron HBP-9030 | ⚠️ **ยังไม่ยืนยัน** — อนุมานจากโค้ดที่เคยเขียนไว้ ยังไม่ได้ทดสอบกับเครื่องจริง |
| AND TM-2655 | ⚠️ **โครงเปล่า** — ยังไม่มีข้อมูลเฟรม |

> ที่ติดป้ายว่ายังไม่ยืนยัน คือยังไม่ได้ทดสอบกับเครื่องจริง
> เอาไปใช้เป็นจุดตั้งต้นได้ แต่อย่าเอาไปอ้างเป็นสเปกของผู้ผลิต
>
> **ถ้าคุณมีเครื่องพวกนี้และช่วยทดสอบได้ จะขอบคุณมาก** — ดูวิธีในคู่มือ

## เครื่องของคุณเป็นรุ่นอื่น?

ทำ profile เองได้ คู่มืออธิบายวิธีถอดรหัสโปรโตคอลของเครื่องที่ไม่มีเอกสาร
ไว้เป็น 6 ขั้น ใช้ได้กับเครื่องอะไรก็ได้ ไม่ใช่แค่เครื่องวัดความดัน

**📋 [อ่านคู่มือฉบับเต็ม](https://andamandev32-pixel.github.io/openmed/guide/)**

เคล็ดลับที่ใช้ได้ทันที — ถ้าเดาไม่ออกว่าฟิลด์ไหนคือค่าอะไร
ให้หาฟิลด์ที่เข้าสูตรนี้

```
MAP ≈ (SYS + 2 × DIA) ÷ 3
```

ถ้าเจอฟิลด์ที่ตรงสูตรพอดี แปลว่าเดาถูกทั้งชุด ไม่ใช่แค่ฟิลด์เดียว

## ติดตรงไหน

- **ต่อแล้วเงียบสนิท** → ลองสลับเป็นสายไขว้ (null-modem) ก่อนเสมอ
  เป็นสาเหตุอันดับหนึ่ง
- **ได้ไบต์แต่อ่านไม่ออก** → baud ผิด ลอง 9600 → 19200 → 38400 → 115200
- **เปิดพอร์ตไม่ได้** → มีโปรแกรมอื่นจับพอร์ตอยู่ ปิดให้หมดก่อน

รายละเอียดทั้งหมดอยู่ในคู่มือ พร้อมตารางแก้ปัญหาตามอาการ
