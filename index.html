ตอนที่ 1 · Smart OPD

ดึงข้อมูลจากเครื่องมือแพทย์ผ่าน RS-232

เครื่องวัดความดันในโรงพยาบาลส่งข้อมูลออกมาตลอดเวลา แต่ส่วนใหญ่ไม่มีใครฟัง คู่มือนี้พาไปตั้งแต่จับสายเส้นแรก จนค่าความดันวิ่งเข้าไปอยู่ใต้ชื่อคนไข้เอง

  • แจกฟรี
  • 24 บท
  • ภาษาไทย
  • ไม่ต้องมีเครื่องจริงก็ทำตามได้
  • พื้นฐาน RS-232 ที่ใช้ได้กับเครื่องยี่ห้อไหนก็ได้
  • วิธีถอดรหัสโปรโตคอลของเครื่องที่ไม่มีคู่มือ
  • กรณีศึกษา Terumo BR-500 และ Omron HBP-9030
  • ต่อเป็นระบบที่ผูกค่ากับคนไข้ได้

โค้ดตัวอย่าง

ดาวน์โหลดไปต่อยอดได้เลย

ตัวอ่านค่า ตัวจำลองเครื่องวัดความดัน และชุดทดสอบ เอาไปใช้ ดัดแปลง ต่อยอดได้ ไม่ต้องขออนุญาต

  • ใช้ได้ฟรี
  • Python
  • ลองเล่นได้แม้ยังไม่มีเครื่อง
pip install pyserial
python device_simulator.py --dry-run --device terumo_br500

คำสั่งสองบรรทัดนี้แสดงให้เห็นว่าเครื่องวัดความดันส่งอะไรออกมา โดยไม่ต้องมีเครื่อง ไม่ต้องมีสาย
