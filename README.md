## มีอะไรบ้าง

### 📋 คู่มือ — ดึงข้อมูลจากเครื่องมือแพทย์ผ่าน RS-232

**[อ่านคู่มือ](https://andamandev32-pixel.github.io/openmed/guide/)** · 24 บท · ภาษาไทย

เครื่องวัดความดันในโรงพยาบาลส่งข้อมูลออกมาตลอดเวลา แต่ส่วนใหญ่ไม่มีใครฟัง
คู่มือนี้พาไปตั้งแต่จับสายเส้นแรก จนค่าความดันวิ่งเข้าไปอยู่ใต้ชื่อคนไข้เอง

- พื้นฐาน RS-232 ที่ใช้ได้กับเครื่องยี่ห้อไหนก็ได้
- **วิธีถอดรหัสโปรโตคอลของเครื่องที่ไม่มีคู่มือ** 6 ขั้น
- กรณีศึกษา Terumo BR-500 และ Omron HBP-9030
- ต่อเป็นระบบที่ผูกค่ากับคนไข้ได้

ทำตามได้ทั้งหมดโดยไม่ต้องมีโรงพยาบาล ไม่ต้องมี HIS และไม่ต้องมีเครื่องวัดด้วยซ้ำ

### 💻 โค้ด — [`code/`](code/)

ตัวอ่านค่า ตัวจำลองเครื่องวัดความดัน และชุดทดสอบ

```bash
pip install pyserial
python device_simulator.py --dry-run --device terumo_br500
```

สองบรรทัดนี้แสดงให้เห็นว่าเครื่องวัดความดันส่งอะไรออกมา โดยไม่ต้องมีเครื่อง
ไม่ต้องมีสาย · [วิธีใช้ทั้งหมด](code/README.md)

**[ดาวน์โหลดทั้งหมดเป็น ZIP](https://github.com/andamandev32-pixel/openmed/archive/refs/heads/main.zip)**

## หลักการเขียน

**แยก "พิสูจน์แล้ว" ออกจาก "ยังไม่ยืนยัน" ทุกจุด**

สิ่งที่ยังไม่ได้ทดสอบกับเครื่องจริงจะติดป้าย ⚠️ กำกับไว้ชัดเจน
เอาไปใช้เป็นจุดตั้งต้นได้ แต่อย่าเอาไปอ้างเป็นสเปกของผู้ผลิต

คู่มือที่บอกว่าตัวเองรู้ทุกอย่าง คือคู่มือที่เชื่อไม่ได้

**ข้อมูลคนไข้ทุกอย่างที่ปรากฏเป็นข้อมูลสมมติ**

## อยากช่วย

ช่องว่างที่ยังเหลือและอยากได้ข้อมูลจากคนที่มีเครื่อง

| เรื่อง | สถานะ |
|---|---|
| โปรโตคอลของ **Omron HBP-9030** | ⚠️ ยังถอดไม่ได้ — ต้องการ HEX dump จากเครื่องจริง |
| **baud ที่ถูกต้องของ Terumo BR-500** | ⚠️ 9600 หรือ 19200 ยังไม่ได้ข้อสรุป |
| ไบต์ตอบกลับที่ BR-500 ยอมรับ | ⚠️ ยังไล่ไม่เจอ |
| ยี่ห้อตัวแปลง USB-to-Serial ที่ทดสอบแล้วใช้ได้ | ⚠️ ยังไม่มีบันทึก |

มีเครื่องรุ่นไหนอยู่และช่วยทดสอบได้ จะขอบคุณมาก —
วิธีเก็บข้อมูลอยู่ใน[คู่มือ](https://andamandev32-pixel.github.io/openmed/guide/)
ใช้เวลาไม่ถึง 10 นาที และวัดกับตัวเองได้ ไม่ต้องใช้ข้อมูลคนไข้
